# NagarLens: Follow the Rupee

NagarLens follows every rupee of monsoon road-repair spending from a citizen's complaint to a fix that held: where each ward's money went, which bills need a second look and why, a fair like-for-like scorecard for every contractor and ward, and where the next rupee should go. Built by Team 11 for Claude Impact Lab Mumbai (21 Nov 2026). This Space runs the web app (Next.js) and the API (FastAPI) in one container.

**Everything shown is synthetic.** The dataset is the organizer's *Follow the Rupee: Mumbai Monsoon Roads* (CC BY 4.0); it is not BMC data, all contractors are fictional, and every amount, date and record is made up. Flags are leads for review, not findings of wrongdoing. This Space runs without an API key, so the explanation panels show deterministic template text.

Source code, setup and the demo script: https://github.com/Mandark-droid/NagarLens
